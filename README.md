# imc-promo-media

`https://dryhurstdigital.github.io/imc-promo-media/<YYYY-MM-DD>/promo-9x16.mp4` (and `promo-16x9.mp4`, `poster.png`)
so social platforms can fetch them. Source: the private repo `dryhurstdigital/imc-promo-video`.
Every video here is already public on Invoice My Clients' social accounts. Nothing secret belongs in this repo.
