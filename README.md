# imc-promo-media

Public hosting for the daily Invoice My Clients promo videos, served through jsDelivr (GitHub Pages is disabled for the org) at
`https://cdn.jsdelivr.net/gh/dryhurstdigital/imc-promo-media@<commit sha>/<YYYY-MM-DD>/promo-9x16.mp4` (and `promo-16x9.mp4`, `poster.png`)
so social platforms can fetch them. Source: the private repo `dryhurstdigital/imc-promo-video`.
Every video here is already public on Invoice My Clients' social accounts. Nothing secret belongs in this repo.
